02Why Financial Services

Three pressures every executive in financial services feels

None of them is a coding problem. They are capacity, risk and speed problems, and Devin is strongest exactly where banks, insurers and asset managers are weakest: old code, security debt and the evidence regulators ask for.

PRESSURE 1

Resilience is a regulatory event

In financial services an outage is not only lost revenue. It is customer harm, an examiner inquiry and, for a material cyber incident, a public filing within four business days.

3 daysCapital One customers locked out after a vendor outage, Jan 2025
4 daysSEC deadline to disclose a material cyber incident

Devin's answer: Devin Oncall investigates alerts and prepares fixes, and every change ships as a reviewed pull request with an audit trail.

PRESSURE 2

The oldest code moves the most money

COBOL still runs core banking, cards and policy administration, and fewer people can change it every year. Banks and insurers also carry decades of systems inherited through acquisitions.

95%of ATM swipes run on COBOL code (Reuters)
220Blines of COBOL still in production

Devin's answer: DeepWiki maps the legacy code, then Devin migrates and tests in parallel.

PRESSURE 3

Regulators now price weak engineering

Data quality, change management and vulnerability backlogs draw consent orders and fines, and the remediation lands on the same engineers who should be modernizing.

$136MCiti fines for slow data remediation, 2024
$80MOCC penalty after Capital One's 2019 breach

Devin's answer: the Vulnerability Program clears the backlog, and Devin does the remediation an exam demands, with the evidence attached.

Why now

Three clocks are already running for these buyers

Peers are scaling agents

Citi is rolling Devin out to 40,000 developers, Goldman Sachs brought it on in 2025, and Fiserv chose it for core banking modernization in May 2026. The cost base for engineering is being reset now.

Resilience rules are live

DORA has applied since January 2025 to firms with EU operations, the SEC four-day cyber disclosure rule is in force, and NYDFS Part 500 is fully phased in. Examiners now ask for evidence, not plans.

Q1 budgets are set in the freeze

Banks and insurers lock down change through year-end close, which is exactly when next year's budget is set. An AE in market in November meets them in planning, not in February.

03Why cloud agents, and why Cognition

Local agents make engineers faster. Cloud agents add engineering capacity.

Cloud agents decouple software production from human attention. A local agent speeds up one engineer. A cloud agent runs in parallel, around the clock, triggered by events, inside enterprise guardrails. That turns software from a labor-bound activity into a compute-bound one.

The company

Cognition describes itself as an applied AI lab building end-to-end software agents. It raised over $2B at a $48B valuation in September 2026 and crossed $1B in annualized run-rate revenue that month, up from $492M in May. Devin writes most of Cognition's own code.

The difference

Devin is not a coding tool. It is engineering capacity as a service, at scale. An agent workforce that compresses the time and cost of the entire software lifecycle, delivered with the change-management muscle large enterprises need to scale it.

Devin plans the work, writes the code, runs the build and tests, and opens a pull request with the evidence the team needs to review and merge it. Developers shift from code writers to architects and systems thinkers.

06Deal and measurement

Where these deals stall, how we qualify them, and how we prove value

Six stalls we plan for from the first meeting, the MEDDPICC checklist every opportunity runs against, and the scorecard every pilot is judged on.

"Our code is too old and too custom"

We start with DeepWiki on one COBOL or core module in week one, with no code changes, and show the Mercedes-Benz and Nubank results.

"Risk won't let an agent near this"

Devin can run in the bank's own VPC, each session in its own VM, every change as a reviewed PR with an audit log. Third-party risk, model risk and the CISO join at M2, not at signature.

"Not during year-end"

We time the land around year-end and quarter-end freezes and start with work that never touches production: documentation, tests and security fixes.

The pilot drifts

No open-ended pilots. One use case, written success criteria and the expansion terms agreed before work starts.

Access stalls after signature

Source control, Jira, Artifactory and change-management access can hold a deployment for weeks. The access plan is signed at M3 with the FDE lead, before the order closes.

A director-level champion alone

Enterprise red tape needs top-down buy-in. An executive sponsor is engaged by M2, and the business case prices open findings, consultant spend and open reqs.

MEDDPICC checklist

Updated after every call and reviewed with my manager weekly. Select a letter to flip it to the proof required before a deal counts in the forecast.

Commit ruleA deal enters commit only when the economic buyer has confirmed the metrics, the use case has met written success criteria, the paper process is dated in a mutual plan, and the champion has been tested.

How we prove value

Measure real output, not token usage

Tokens spent, ACUs consumed and raw pull request counts are easy to game and prove nothing to a CFO. Every pilot is scored on outcomes the customer already cares about.

What we do not sell on

  • Tokens or ACUs consumed
  • Raw pull request counts
  • A savings percentage promised before discovery

What we measure

  • Productive engineering hours delivered, in human-equivalent terms
  • Time to deliver against a deadline the customer has already named
  • Business outcome: findings closed before the exam, a migration date that holds, a release that ships before quarter-end

How it expands

A paid pilot proves one outcome on one dated priority. That result becomes the proof point the champion takes to the next business unit, and Cognition backs it with a guarantee that Devin delivers more engineering value than it costs. Cognition has described one banking customer growing from $1.5M to over $15M in eight months as Devin moved from a pilot team to the full organization.
